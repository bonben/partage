What the paper does not say

These parameters had to be assumed. If one of them is wrong, the correction is what we need most.

  1. Tmax counts the first SC attempt (Tmax = 10, 100, 400).
  2. Approximate metric: f*(x) = 1.5 if |x| <= 5, else 0 (constant shift), alpha = 0.3.
  3. Flips inside R1 nodes restricted to the 2 least reliable bits, inside SPC nodes to pairs among the 4 least reliable.
  4. The CRC bits are appended after the information bits (AFF3CT convention).
