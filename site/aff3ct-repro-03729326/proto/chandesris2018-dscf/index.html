What the paper does not say

These parameters had to be assumed. If one of them is wrong, the correction is what we need most.

  1. The x-axis "SNR" is read as Eb/N0 (the paper does not say).
  2. alpha = 0.3 for every Eb/N0 (the paper fits alpha against the SC error rate; 0.3 is the value of the practical follow-up papers).
  3. Gaussian approximation as implemented in AFF3CT, designed at the simulated Eb/N0.
  4. The SC curve of AFF3CT is on the 528-bit information set (K + CRC); the paper's SC is probably on K = 512, hence a baseline only.
