What the paper does not say

These parameters had to be assumed. If one of them is wrong, the correction is what we need most.

  1. Greedy selection of the automorphisms (Kestel et al. 2023) run once at 3.5 dB and reused at every Eb/N0; the selected set is in inputs/.
  2. Floating point decoding (the paper uses 6-bit LLR and 8-bit path metric quantization: AFF3CT is expected slightly better).
