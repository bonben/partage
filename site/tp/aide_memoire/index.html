Adresses et registres¶

IP Adresse Registres Interruption
Chenillard 0x43C00000 +0 mode, +4 vitesse, +8 motif du mode 0 non
Boutons (AXI GPIO) 0x41200000 +0 données, +0x11C GIER, +0x128 IER, +0x120 ISR oui
Interrupteurs (AXI GPIO) 0x41220000 +0 données non utilisée

Modes du chenillard : 0 motif fixe (registre +8) ; 1, 2, 3 rotation vers la gauche de quatre, deux ou une LED ; 4 à 7 rotation vers la droite ; 8 et plus : séquences pseudo-aléatoires.

Diagnostiquer : où regarder¶

Question Où regarder
Le noyau connaît-il mon IP ? ls /sys/bus/platform/devices
Que dit le device tree ? /proc/device-tree/amba_pl/
probe a-t-elle été appelée ? dmesg, ls /sys/bus/platform/drivers/<driver>/
Qui a réservé ces registres ? cat /proc/iomem
Quel numéro majeur a mon driver ? cat /proc/devices
L'interruption arrive-t-elle ? cat /proc/interrupts, avant et après
L'IP répond-elle sans driver ? devmem <adresse> 32

probe jamais appelée : souvent un compatible qui diffère d'un caractère.

Commandes utiles¶

Sur le poste
SETUP MEE_VIVADO_CLASSROOM compilateur croisé, dans chaque nouveau terminal
tio /dev/ttyACM0 console de la carte (Ctrl+T puis Q pour quitter)
cd /srv/nfsroot/arkane/home/user/tp le dossier de travail ; sur la carte : /home/user/tp
file programme pour quelle architecture est-il compilé ?
Sur la carte
insmod module.ko, rmmod module, lsmod charger, retirer, lister les modules
dmesg \| tail derniers messages du noyau
devmem adresse 32 [valeur] lire ou écrire un mot en mémoire physique
top charge CPU par processus (q pour quitter)

En cas de blocage¶

  • La console ne répond plus : quittez tio (Ctrl+T puis Q), relancez-le. Si rien ne vient, bouton PS-RST de la carte.
  • insmod refuse le module (invalid module format) : il n'a pas été compilé contre le noyau de la carte. Recompilez avec le Makefile fourni, sans le modifier.
  • ./programme: not found sur la carte alors que le fichier est là : il a été compilé pour le PC. Vérifiez avec file sur le poste.
  • Un module ne se retire pas (rmmod : Resource temporarily unavailable) : un programme a encore son fichier ouvert. Arrêtez-le d'abord.
