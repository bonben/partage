    0. Mise en place¶

    Commune aux deux TP. À faire une fois, au début.

    La carte¶

    La carte est déjà câblée (alimentation, USB de la console sur J14, Ethernet vers le poste) et déjà flashée. Mettez-la sous tension : elle démarre seule, en moins d'une minute.

    Ce qu'elle exécute au démarrage, dans l'ordre : le FSBL, qui configure le processeur et charge le bitstream du FPGA ; U-Boot ; le noyau Linux 5.4 ; puis BusyBox, depuis un système de fichiers que le poste lui sert par le réseau (NFS).

    Le poste¶

    Ouvrez deux terminaux.

    Sur le poste, terminal 1 : l'environnement de compilation
    SETUP MEE_VIVADO_CLASSROOM
cp -r /users/local/arkane/tp /users/local/arkane-$USER
cd /users/local/arkane-$USER

    SETUP MEE_VIVADO_CLASSROOM donne le compilateur croisé arm-linux-gnueabihf-gcc. Il est à relancer dans chaque nouveau terminal où vous compilez.

    Sur le poste, terminal 2 : la console de la carte
    tio /dev/ttyACM0

    Appuyez sur Enter : l'invite de la carte (/ #) apparaît. Pour quitter tio : Ctrl+T puis Q.

    Pas d'invite ?

    Vérifiez que la carte est sous tension (LED verte POWER), puis appuyez sur le bouton PS-RST de la carte et regardez défiler le démarrage dans tio. Si le noyau s'arrête sur VFS: Unable to mount root fs ou nfs: server 192.168.74.1 not responding, c'est le serveur NFS du poste : débranchez l'adaptateur USB Ethernet, rebranchez-le sur un autre port USB, puis PS-RST. Sinon, appelez le formateur.

    Envoyer un fichier sur la carte¶

    Le dossier /home/user de la carte est en réalité un dossier du poste. Le script envoyer y copie vos fichiers :

    Sur le poste
    ./envoyer tp1/hello
    Sur la carte
    cd /home/user
ls -l

    Les fichiers fournis¶

    Dossier Contenu
    tp1/ hello.c, devmem.c (à compléter), Makefile
    tp2/ les drivers chenillard.c et axi_btns.c, les applications app.c et thread_app.c, les scripts load.sh et unload.sh, Makefile
    envoyer le script de copie vers la carte
